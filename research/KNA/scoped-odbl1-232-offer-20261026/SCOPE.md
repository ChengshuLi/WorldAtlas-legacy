# Scope of the KNA 232 assignment object

This directory contains a narrowly defined, complete 232-cell owner-assignment product: `native-requested-patch-232.json` and `native-patch.schema.json`. The table has 232 assignments in 61 rows and 79 half-open runs, using native owner pixel index 7119. Its proposed scoped license and source attributions are in `SOURCE-NOTICE.md`.

Conservation against the original KNA scope is 305 keys / 125 intervals: 57 previously accepted Nevis keys are not part of this change; 232 St Kitts keys are included; 16 St Kitts keys that are inside the simplified source but outside the full-source comparator remain held and are not included. The separate 154-cell physical companion is excluded. No source geometry, private comparison rows, raw source archive, or physical-result payload is included.

The recorded comparison is representative-point source contact only. It does not establish legal status, physical completeness, native/current selector acceptance, current ownership acceptance, or science credit. Source provenance includes conflicting archived CC BY-SA 2.0 metadata and a bundled notice distinguishing ODbL for OSM data from CC BY-SA 2.0 for documentation; see the scoped notice for details.
