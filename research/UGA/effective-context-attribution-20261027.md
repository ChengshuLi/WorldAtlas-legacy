# Effective-context attribution appendix — catalog-derived families

## Inputs and counting rule

This source-free appendix inventories the feature IDs with non-null geometry in the 34-file effective-context inventory, then groups `gb:*` IDs by the exact first three ID segments (`gb:ISO:ADM`) and joins those family keys to the committed administrative-source catalog. The script read feature IDs and geometry-presence only; no coordinate or geometry values are included here.

- Effective-context manifest: `research/UGA/private/uga-finalize-output-003-resume-review-20261027/manifest.json`; SHA-256 `4700640b982fac872d5b59c3c582069ecc1e5607ea87adfb7ebd0985c8714651`. The exact current-startup database is 79 unique indexed body files plus index and selection; 30 compatibility references overlap existing bodies and are not 30 additional unique bodies.
- Catalog: `data/administrative-sources.json` at commit `341556d19032504a2cc33256937f70ff766a271c`; blob `2747b845f0c5654765da3b951c9074e52f220077`, 661,416 bytes, SHA-256 `ed0051d2956271c72f8917e7da0c6f53e5dfb595bee5920cac489a65a747d633`.
