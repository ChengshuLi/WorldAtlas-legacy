# ARG343 scoped source-role proposal

This folder records a source-role interpretation for exactly 343 retained original ARG ADM2 land keys. It does not change geometry, membership, owner, status, acceptance, or credit. The complete original BRA ADM1 source remains a competitor and is referenced by immutable pins; no source geometry is copied here.

`scope.json` is the exact 343-key native-index scope. `decision.json` records the source-version rationale, evidence pins, adjacent preserved strata, and limits. The next file, `territorial-applicability.json`, binds each scoped key to the target-specific original negative ordinal and geometry hash, with separate source feature ordinals and provenance references.

The source history is limited to the evidence actually retained: IBGE MMD2025 documents the 2015 Argentina/Uruguay trace update defined by SCDL and available from MRE, and says those traces are fully incorporated in 2025. This explains a source-version difference; it does not establish legal attribution or eliminate the original 2006 BRA source as adverse context. Current IGN/IBGE comparisons are likewise contextual only.

The 37 other BRA-contact keys, 636 CHL contacts, 8 PRY contacts, 32 CABA membership keys, 4 source-fitness keys, the separate TDF4502 scope, and every other residual remain outside this proposal. No native diagnostic, stock operation, review, or publication is run by this record.
