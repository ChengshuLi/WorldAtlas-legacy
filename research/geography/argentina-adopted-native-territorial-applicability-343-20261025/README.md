# ARG343 scoped source-role proposal

This folder records a source-role interpretation for exactly 343 retained original ARG ADM2 land keys. It does not change geometry, membership, owner, status, acceptance, or credit. The complete original BRA ADM1 source remains a competitor and is referenced by immutable pins; no source geometry is copied here.

`scope.json` is the exact 343-key native-index scope. `decision.json` records the source-version rationale, evidence pins, adjacent preserved strata, and limits. `territorial-applicability.json` binds each scoped key to its target-specific original negative ordinal and geometry hash, with complete source, adoption, and scope references. `author-input-manifest.json` records custody pins and counts.

The ordinal spaces are distinct: each `original_source.pointer` names a complete-source feature ordinal (`/features/24/geometry`, `/features/25/geometry`, or `/features/26/geometry`); the separate `negative_ordinal` field is the exact target's territorial-exclusion array slot (0 or 1). For owner 7965, 270 keys split across two BRA operands: 219 use source feature ordinal 24 / target negative ordinal 0, and 51 use source feature ordinal 25 / target negative ordinal 1. Each key has one BRA contact.

IBGE MMD2025 technical notes document 2015 adjustments to Paraná, Santa Catarina, and Rio Grande do Sul using Argentina/Uruguay traces defined by SCDL and available from MRE; they also describe full incorporation in 2025. This is a source-version explanation, not a legal territorial ruling or proof that every historical overlap is erroneous. Current IGN/IBGE comparisons are contextual only.

The 37 other BRA-contact keys, 636 CHL contacts, 8 PRY contacts, 32 CABA membership keys, 4 source-fitness keys, the separate TDF4502 scope, and every other residual remain outside this proposal. No source/physical producer, native diagnostic, stock operation, public review, or status action is run here.
