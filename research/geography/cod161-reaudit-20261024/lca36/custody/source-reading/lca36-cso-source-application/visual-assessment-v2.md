## Exact control method and limits

`cso-pdf-controls.json` records each untouched source hash, page box, exact `/VP` viewport, `/BBox`, `/Measure`, `/GPTS`, `/LPTS`, full declared `/GCS` WKT, optional-content names and available installed PROJ operation definitions. The full render PNGs are unchanged map pixels.

For the five2013 bodies, the literal WKT resolves locally to EPSG2006. Four published geographic control pairs were converted within that declared coordinate system to its projected coordinates, then related to the supplied page-control pairs by a three-parameter affine calculation per page axis. No map edge or landmark was selected to obtain the mapping. The maximum four-control consistency residual was0.00998–0.03205 PDF points. That is only internal consistency of rounded PDF controls; it is not a geographical error bound.

The source reader follows the published control semantics described in GDAL's `PDFDataset::ParseMeasure` implementation, particularly the geographic-to-declared-projected conversion and LPTS/BBox relationship ([primary implementation](https://raw.githubusercontent.com/OSGeo/gdal/master/frmts/pdf/pdfdataset.cpp), inspected lines6518–6845). The Library of Congress [format description](https://www.loc.gov/preservation/digital/formats/fdd/fdd000315.shtml) likewise distinguishes map control from normal rendering. A search for the older Adobe supplement led to an archived Level5 document that did not supply the desired Level3 section; no claim of having read that missing section is made. The current PDF2 errata were not substituted for the older encoding semantics.

Existing native latitude literals and the previously authenticated width262166 longitude inverse were preserved. Their ordinary WGS84 geographic interpretation was used **conditionally**, with both installed non-ballpark St Lucia1955 transformations: inverse St Lucia1955→WGS84(2), stated parameter accuracy2m; and inverse(1), stated10m. These values are operation metadata, not map accuracy. Both operations explicitly name **St Lucia—onshore**. Their use in this diagnostic does not establish an offshore domain, tidal limit or territorial classification; the seaward visual outcomes make that limitation particularly material. The two resulting page positions and their spread are preserved per key rather than selecting the more favorable one.

The calculations only locate a reader position on a published page. No new native membership observation was executed. `render_conditional_windows.py` renders original PDF pixels in90×90-point windows, at3 pixels per point, centred on operation(2). No map content is redrawn or erased; operation(1)'s relative offset is in JSON. Human visual reading of those windows and full maps supplies the reported coastal context. The first attempted plotting helper failed because matplotlib was not installed; no package was installed and no plot from it was claimed. The source-window renderer completed normally.
