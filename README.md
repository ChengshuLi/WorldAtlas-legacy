# Historical WorldAtlas evidence (review draft)

This payload combines compact, losslessly compressed WorldCover 2020 v100 observation and disposition records with small historical root-holder proposal patches/scripts. The proposals are unadopted research artifacts; they are not accepted implementation, production output, or evidence that issue #1394 was completed.

The IDN JSONL files are preserved byte-for-byte inside deterministic gzip members. They are historical observations, not a new source read or newly validated scientific answer. Attribution: ESA WorldCover project 2020; contains modified Copernicus Sentinel data (2020) processed by the ESA WorldCover consortium. License: CC BY 4.0. Source reference: https://esa-worldcover.org/en/data-access. The retained source-observation metadata says complete source-file hashes were not claimed, so this payload does not claim full immutable source-byte recovery.

The original proposal filenames and directory groupings are retained. No raw geometry package or unrelated runtime data is included. The draft manifest records exact local source-to-payload hashes and modes.
