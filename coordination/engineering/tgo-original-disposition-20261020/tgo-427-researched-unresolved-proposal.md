The finite remaining predicates are:

1. **Source role and vintage:** establish an attributable source lineage and applicable source version for the 2017 ADM2 operand; retain the 20 ADM2-only cases as a distinct source-layer discrepancy until independently resolved.
2. **Competitor applicability:** obtain complete, attributable candidate-source operands and a valid per-key source-to-target association where a competing source is alleged. A zero-contact count in the original packet or absence in the frozen raster candidate records is not a negative territorial finding.

The current 509-row witness is only land-mask and has no exact location contacts; no supported first execution can create them from the retained inputs.
4. **Current native qualification:** use the accepted current-owner/native procedure with its exact selector and conservation evidence; the historical owner-zero snapshot does not satisfy this predicate.

Stop this proposed work item after one bounded retrieval/application attempt for those named missing operands through the supported routes. If the required records remain unavailable, retain unresolved status rather than substituting place names, incomplete candidate lists, a legal-certificate presumption, or owner-zero inference. No additional geometry, source replay, broad legal search, or interval expansion is implied by this proposal.
