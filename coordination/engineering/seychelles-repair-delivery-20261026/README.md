# Seychelles ADM2 source-relative evaluation

This package retains the complete original 2,458-cell, eight-owner claim. It
does not change ownership, make a legal-boundary or sovereignty finding, or
certify the completeness of remote islands. The original 2018 ADM1 contacts,
physical/native findings, adverse results, and source-limit notes remain
separately preserved in the source-role assessment.

## Physical source terms and limits

The original physical source is GSHHG 2.3.7. The pinned retained
`LICENSE.TXT` says LGPL version 3 or later; the archived GSHHG changelog says
version 3 or any earlier version; the upstream GSHHG repository describes the
project as distributed under the GNU Lesser General Public License. This
version wording conflict is preserved rather than resolved by inference.
The data also have known vintage, scale, and positional limitations. Physical
output is source-relative evidence only, not legal attribution or proof of
all-island completeness.

## Method status

`source-stage-001` is an identity-only join of all eight exact original source
features to the same-ID current selected features. It does not simplify,
repair, clip, transform, or overlay either geometry. The whole-target physical
stage, native constructor, and selected-owner checks are separate operations;
their results and limits must be reported independently. No acceptance or
credit is implied by this package directory.
