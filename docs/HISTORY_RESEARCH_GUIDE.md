# Historical-content research guide

This lane collects evidence for dated factual attributes and prepares scoped content proposals. It does not change application code, schema, UI, infrastructure, geography, categories, releases or grid assets. The user chooses the model; Luna is permitted when selected. Geography evidence is a separate lane in [GEOGRAPHY_GUIDE.md](GEOGRAPHY_GUIDE.md), and engineering owns executable integration and publication.

## Scientific and source contracts

Use [ATTRIBUTE_CONTRACT.md](ATTRIBUTE_CONTRACT.md), [HISTORICAL_COVERAGE_RESEARCH.md](HISTORICAL_COVERAGE_RESEARCH.md), [ENVIRONMENT_CLASSIFICATIONS.md](ENVIRONMENT_CLASSIFICATIONS.md), and the applicable source/license guidance. The [historical content API reference](HISTORICAL_CONTENT_API.md) documents identity and graph readers; it is not live-operation authorization. Preserve exact stable IDs, original source bytes or lawful restoration references, vintage, licenses, dates, method, uncertainty, and actual retrieval/processing limits. Store only supported sparse half-open intervals; no year zero, fabricated annual rows, interpolation, or inference from modern reference context. Missing evidence remains unknown.

## Scope and deliverables

Follow current accepted `AGENTS.md` and [WORKER_COORDINATION.md](WORKER_COORDINATION.md) for scope, ownership and delivery. Work only in the assigned `research/campaigns/<campaign-id>/` directory, reusing retained source/result evidence when its inputs and method still apply. A new campaign can link prior evidence; it must not overwrite another campaign or invent a progress tracker. Proposals state exact subjects, completed source application, adverse findings, unresolved questions and remaining reasonable source opportunities.

Offline preparation, an accepted PR, historical import receipts or a dry run do not grant live access. Before any proposed import, verify the accepted-main `data/research-geography-gate.json`, the exact region/campaign certificate and release pins, and explicit current authorization for that operation and destination. Unless all support that exact action, remain in evidence research/staging; do not request private service credentials or use the retired Site. Never silently repin, weaken source limits, or treat matching names as identity evidence.

Keep current work and next actions on the existing GitHub issue/PR discussion. A completed bounded campaign is not worldwide completion. Preserve original dates and receipts; distinguish research, staging, import/read-back, publication, and scientific acceptance.
