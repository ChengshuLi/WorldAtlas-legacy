# WorldAtlas worker entry points

At start or resume, follow accepted [`AGENTS.md`](../AGENTS.md). [WORKER_COORDINATION.md](WORKER_COORDINATION.md) is the sole current general guide for worker identity, scope, allocation, reviews, queue/delivery and issue coordination. Read the matching role-specific guide/prompt below for role duties and acceptance; it does not override current accepted procedure. Never reset a dirty primary checkout to refresh it; preserve scientific inputs, results, pins and source restrictions from older task notes.

Repository: https://github.com/ChengshuLi/WorldAtlas. GitHub Issues holds current scope, progress and acceptance history. Models are selected by the user; geography and history research may run on Luna when selected. Use the current accepted issue/release records for status and the specific live-operation runbooks for authorized provider work.
